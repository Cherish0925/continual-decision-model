# Open research questions after experimental memory

Consultation brief for [CDM v0.14.0](https://github.com/Cherish0925/continual-decision-model/releases/tag/v0.14.0), source revision [`6c0d991`](https://github.com/Cherish0925/continual-decision-model/tree/6c0d991eae0e628e2ea10b0c2de3ff59b0bc5186). Read the results at this revision before proposing changes. Where later work changes an answer, identify that revision separately.

**Central question.** In a changing world, when should an agent use an old explanation, choose an experiment that distinguishes competing explanations, continue thinking, or start learning something new? The choice has to improve the actions that follow while the world continues to move.

The intended CDM ingests asynchronous observations, keeps unfinished inference alive, responds to requests and can initiate useful work without a new request. Quiet periods can support cheaper inference, replay and consolidation. The experiments below establish a narrower ability. We want an independent scientific assessment and an implementable alternative, including the option to replace parts of the design.

## What has changed

In the main study, physics and chemistry share core weights and have separate recurrent states. The chemical policy receives structured observations. At a signaled apparatus boundary, it archives public measurements. It does not receive the relationship identity or a return flag. A current-task predictor competes with one reconstructed predictor per compatible archive. Before each next observation, each predictor assigns a likelihood to its outcome. The accumulated likelihoods help weight old predictors. Writes are automatic; response fitting takes four steps. Neither is a learned decision to spend computation. Carrying observations is distinct from changing shared weights during deployment.

| Primary chemistry cost (mean native operations) | New, seed 911 / 912 | Returning, seed 911 / 912 | Overall, seed 911 / 912 |
| --- | ---: | ---: | ---: |
| Independently trained without archive use | 93.85 / 84.74 | 88.67 / 83.07 | 91.26 / 83.90 |
| Learned archive reader | 98.00 / 100.38 | 59.33 / 64.23 | 78.67 / 82.31 |
| Same weights with fixed likelihood-based reader | 96.58 / 100.80 | 58.73 / 63.17 | 77.65 / 81.98 |

All three conditions finish all 240 chemical tasks; 120 are new relationships and 120 returns. The paired intervals favor archive use on returns in both continuations, and overall in one. Clearing chemical recurrent state while retaining the archives preserves the return benefit. A known-family Bayesian reference, direct successful-recipe retrieval and a trained no-memory policy are different comparisons, with different assumptions. The 5,280 primary executions share 480 distinct physical and chemical instances.

Two further results change the next experiment. Increasing the fixed reader from six to twelve ledgers on a second 120-task chemistry cohort reduces overall operations from 78.02 / 85.38 to 69.97 / 75.02; long returns improve and short returns become costlier. Extra training that passes action-return gradients to the reader gives changes of −3.63 and +0.57 operations relative to prediction-only continuation; both intervals span zero. A two-experiment planner already propagates hypothetical outcomes into memory weights; it did not beat the learned policy on the development comparison. An internal operation count, a lower prediction loss and a better acting policy answer different questions.

The return frequency itself changes the practical conclusion. Holding these measured new/return means fixed, the memory model breaks even against no memory at about 12% returns in one continuation and 45% in the other: the new-task penalty divided by that penalty plus the return-task saving. This is a reweighting of the published means, not a prediction for a different schedule; varying recurrence changes which records survive. What distribution of interruptions and novel tasks preserves the gain?

## Questions for a research collaborator

**1. What is the scientific claim, and what could replace the present design?** Give the strongest sentence the existing results support and the stronger sentence a future paper should earn. Identify the closest prior for each, including any work that would make the proposed contribution routine. Compare episodic meta-RL, latent-task inference, sequential experiment design and learned allocation of internal computation. Which assumption or prediction would distinguish CDM from those methods? Offer one materially different architecture, and the strongest reason it could be simpler or better. Do not assume that GRU, a Transformer workspace and an archive must all survive.

**2. Which experiment should the agent choose when memories disagree?** The action interface reads mixed response predictions; the individual predictors' disagreement is not an explicit action feature. Consider two equally likely contexts: a probe can give outcome probabilities (0,1) across contexts, or (0.5,0.5). Both average to 0.5; only the first identifies the context. Identification is useful only if it changes a later action enough to pay for the probe. Construct a case with native action costs and an irreversible or censored observation. Can such a pair be found in the actual simulator, and does the existing state or another action feature already distinguish it? Specify a value target that compares probing with acting now. Compare against a myopic information-gain rule, a cost-aware Bayesian policy, and the existing contingent two-experiment planner. What result would show that expert disagreement is irrelevant here?

**3. When is old knowledge identifiable, and what should memory contain?** Separate a missing old record, a present but poorly reconstructed record, and two genuinely indistinguishable relationships. How many observations does each require, and when is even a perfect selector unable to tell? Compare recency, a fixed likelihood mixture, episodic retrieval, and a learned reader at equal observation and byte budgets. Should the memory store episodes, sufficient statistics, predictive functions, experiments that distinguish hypotheses, or reusable procedures? How should duplicates, confidence, age and imperfect similarity affect read, write, merge and eviction? Include a fresh-task option; explain how to estimate the cost of wrongly reusing an archive without providing the hidden identity to the agent. Check when apparent transfer is just replaying a known successful recipe.

**4. What must persist, what should remain plastic, and what should be discarded?** Specify state transitions for the fast recurrent state, unfinished workspace, task-specific adaptation and slower shared knowledge. Compare a minimal recurrent agent, the present core and an alternative with addressable state, all with the same data and tools. What breaks if a workspace never survives across tasks? When can quick online updates help beyond conditioning on observed history? Design quiet-period replay or distillation whose benefit is measured on *later* tasks after the original ledger is unavailable. Count its latency and compute. How should a model recognize what it can do, what it cannot yet do, and which uncertainty is worth investigating? Make this self-model predict something measurable about its own future performance.

**5. How does initiative arise in a world that keeps moving?** Specify who chooses the next observation, internal update, action, tool call, goal or wait: the model, an environment event or a fixed runtime rule. Give a task in which an unprompted intervention pays off, and a matched situation in which waiting is better. Give the timeline when an instrument changes mid-plan and a delayed reading from an earlier action arrives. How does the agent interrupt, revise or resume a computation, attribute delayed outcomes to actions, and avoid issuing a stale command? Which operations can run cheaply while idle and which require deeper computation? Compare learned allocation against a fixed or event-triggered schedule at matched latency and compute. Include one case where more thinking makes the action worse because the opportunity expires.

**6. What training data and feedback will teach the desired choices?** Define the observation before an action, the selected action and time, the returned observation, cost, and the next target. The chemical return can be censored; only the chosen experiment is observed online. Distinguish actual interaction, offline trajectories, simulator branches available to a trainer, and information permitted at inference. Derive or give pseudocode for a learning objective that makes a useful measurement, a useful memory write, or an extra computation valuable through later decisions. How long must credit cross task boundaries? Where is the graph truncated, which gradients should reach the reader, and why should this change behavior when the existing reader-only action gradient did not? Suggest one alternative to more scale that the current logs can discriminate. Define the training curriculum, initialization from released weights, and the partition by task family, return schedule and random seed.

**7. Do the learned representations generalize across tasks and modalities?** The chemistry update uses closeness of normalized proportions, which matches the simulator's cosine-based response geometry. Compare this fixed metric against a learned metric and a method without it. Change the *response family*, not only the seed or ingredient names; preserve uncertainty and experimental cost so the comparison remains meaningful. Which result would distinguish chosen priors from learning a transferable notion of relevance? Joint physics/chemistry weights are not by themselves evidence of cross-domain transfer: what useful procedure could transfer, what baseline receives identical exposure, and what previous ability might be lost? For vision, text and sensor streams specify what becomes available from raw observations, what a structured tool supplies, where a frozen encoder or semantic model belongs, and how actions are decoded. Include a structured-only control and a case where pixels or timing actually matter.

**8. What comparisons would change a research decision?** Keep the strong 12-ledger fixed reader as well as the six-ledger condition. Include a separately trained recurrent meta-RL agent, explicit Bayesian context memory, and a latent-context agent; if claiming general discovery ability, include a published discovery agent with comparable observations and tools. Distinguish a prior that knows the function family from a method that must learn it. Keep initial simulator states, action costs and tuning budgets comparable; separately report a fast no-memory deployment that skips archive work. Randomize recurrence order and delays and withhold new families, instead of relying on the single published 12-task order. Use new final streams and independently trained seeds; compare per-stream differences and variation across seeds without counting shared instances as new samples. Report completion, native operations including failures, new versus returning tasks, delay, decision latency and compute. Which next benchmark would test a missing property? Which would merely add another leaderboard?

**9. Can this architecture be trained, run continuously and deployed economically?** For the current two-H100 setup, show where time goes: simulator stepping, batching and transfers, recurrent core, archive reconstruction, candidate scoring and backpropagation. Measure before predicting throughput. How would you batch streams of unequal length, cache only valid shared computation, and interrupt work when late observations arrive? Compare bounded attention, recurrent or scan-friendly alternatives and a smaller fixed reader at equal wall-clock cost. What belongs on the single-instance fast path and what can be trained or replayed asynchronously? Give a route from a digital world to one closed-loop instrument task, such as tracking a drifting optical alignment from delayed camera or power readings. Identify the new physics, data and latency requirements; report simulation and physical experiments separately.

## Proposed first decision

Should the next change be to the **experiment selector**, the **representation of old and new relationships**, or neither? Start with the twelve-ledger fixed reader, a fresh-task expert and the existing policy. At a common observable prefix, compare two feasible first experiments under the same remaining budget and subsequent policy. Use independent simulator continuations for training or analysis; never expose unchosen outcomes to the acting agent. Compare a selector that sees only mixed predictions with one that also sees the alternatives. It is possible that the task rarely offers a decision where this information matters; establish that before a large training run. If it does matter, preserve the initial action scores when connecting new features so the experiment measures learning rather than an accidental change of behavior.

Please return (1) the present claim and its nearest competing explanation; (2) two or three genuinely different mechanisms, with one recommended and one dropped; (3) state, update, action score or pseudocode precise enough to implement the recommendation, including file-level changes; (4) one first matched experiment on two H100s, plus the result that would change the recommendation; and (5) the larger study needed for a paper. Identify missing information by naming the file, observation or measurement that would resolve it. If one can answer a question from a published table or a short calculation now, do that rather than proposing another run. Cite the original papers and separate existing measurements from proposed ones.
