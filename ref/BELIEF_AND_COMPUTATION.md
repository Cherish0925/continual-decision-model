# Belief, memory and computation: the closest comparisons

**Focused update, 3 November 2026.** This note supports the [current research direction](../research/CONTINUAL_AGENT.md), extending the broader [comparison](COMPARISON.md). Primary sources establish the overlaps below. The function-belief study now implements conditional and attention-based predictors alongside learned latent functions; the remaining methods retain their stated comparison requirements.

| [Practical Transfer Learning for Bayesian Optimization](https://arxiv.org/abs/1802.02219), Feurer et al., 2018 preprint, revised 2022 | Ranking-weighted Gaussian-process ensembles transfer surrogate information from earlier optimization tasks | Useful for testing source-model weighting and negative transfer. Ranking weights differ from CDM's likelihood-based weighting; an adapted optimization baseline must respect the changing physical state. |

## What the proposed method must add

The candidate is **decision-relevant reuse of learned relationships and unfinished inference**: represent uncertainty within old and unfamiliar laws; update it from chosen, possibly censored or delayed observations; use the resulting predictions to value actions and further computation; train later-use updates across task changes.

None of those phrases alone establishes originality. State the actual representation, transition or training difference and compare it with the nearest method in the table. A useful result would show that the difference reduces future experiment cost or improves timed control under response-law changes, while preserving old competence. Merely combining a GRU, Transformer, adapters, episodic records and an activity head does not answer that question. Conversely, known components do not rule out an original learning mechanism or systems result.

The first learned baselines should be recurrent meta-RL and latent-context meta-RL, followed by episodic recall for the memory claim. Use a cost-aware known-family planner to quantify the value of having the correct response model. MAML-style adaptation, ordinary replay and fixed learning schedules belong in the update/consolidation comparisons. Dreamer or another broad world-model agent becomes a direct baseline when the tested task and claimed scope require learned long-horizon dynamics; listing it without a matched implementation adds no comparison.

## Information and resource matching

Report differences that determine what each method can infer: known response law, latent task labels, public task boundaries, observation noise, tools, complete versus censored outcomes, and which historical records remain available. Privileged references are useful but should be identified as such.

Train independently optimized alternatives as well as same-weight interventions. Match task interactions, tuning opportunities and retained memory where relevant. Report quality against environment operations, training compute and actual decision latency; these are different budgets. A method using fewer experiments but much slower computation can still be valuable for an expensive instrument, while being unsuitable for fast control.

Use the broader surveys for [continual learning](CONTINUAL_LEARNING.md), [internal computation](INTERNAL_COMPUTATION.md), [planning](PLANNING.md) and [world models](WORLD_MODELS.md) when implementing each study.
